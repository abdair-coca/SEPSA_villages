# Archivo histórico

`archive/legacy/` conserva la documentación anterior a la consolidación de 2026-09-27, además del `.docx` de especificación previa (su nombre es un prompt, `ROLE_Actúa como…`) y del redirect `constitution-redirect.md`, que apuntaba a `RULES.md`. También guarda el prototipo `boceto-mvp/`, que no es documentación vigente.

`limpieza-estructural/` guarda el plan de la limpieza estructural (fases 0 a 7) y su TASK final, con los hallazgos abiertos. El estado exacto del repositorio al cerrarla está en la etiqueta `limpieza-estructural-cerrada`.

`entrega-sepsa/` guarda los pendientes abiertos de la entrega documental (fases F5 a F8) y los conflictos detectados contra el plan de consolidación, con sus hallazgos.

No leer este directorio para una tarea normal. Consultarlo solo cuando se necesite:

- recuperar evidencia o procedencia de una decisión;
- comparar una etapa anterior;
- revisar una auditoría o propuesta histórica;
- migrar criterios que todavía no estén representados en los documentos activos.

Los documentos activos son la fuente de trabajo: `PROJECT.md`, `ARCHITECTURE.md`, `DOMAIN.md`, `RULES.md`, `DECISIONS.md` y `features/`. El archivo histórico no debe elevar una hipótesis, endpoint o diseño antiguo a regla vigente sin validación.
