# 02 - Módulos del Ecosistema SEPSA

El ecosistema SEPSA está compuesto por cuatro módulos funcionales integrados:

| Módulo | Subdominio / Aplicación | Propósito Principal | Pantallas Asociadas | Confianza |
| --- | --- | --- | --- | --- |
| **M1** | [cortes.sepsa.net.bo](cortes/overview.md) | Gestión web de órdenes de corte, filtros de mora territorial, bandeja de cuadrillas, fichas de corte y reposición. | P-01, P-02, P-03, P-04, P-05 | [CONFIRMADO VISUALMENTE] |
| **M2** | [cobros.sepsa.web.bo](cobros/overview.md) | Recaudación en ventanilla, consulta de Kardex contable, auditoría de planillas y alertas fiscales. | P-06 | [CONFIRMADO VISUALMENTE] |
| **M3** | [nexo.sepsa.bo](nexo/overview.md) | Despacho y recepción móvil de asignaciones técnicas de corte para brigadas. | P-07 | [CONFIRMADO VISUALMENTE] |
| **M4** | [QField / QGIS](gis/overview.md) | Cartografía SIG satelital móvil para navegación de cuadrillas y auditoría de capas eléctricas. | P-08, P-09 | [CONFIRMADO VISUALMENTE] |
