# SEPSA · Guía de campo — Piloto (1 página)

**App:** SEPSA Campo (PWA Android) · **Uso:** con y sin internet · **Regla de oro:** sin autorización online vigente, NO hay corte.

## 1. Antes de salir (con internet, 5 min)

1. Conectate a WiFi o datos.
2. Abrí Chrome y entrá a: **___________________________** (pedir URL a tu supervisor).
3. Iniciá sesión con tu usuario técnico. No uses incógnito.
4. Esperá que cargue **Jornada de campo** y veas **Mis órdenes**.
5. Abrí cada orden y verificá: cliente, dirección, medidor, deuda.
6. Descargá el mapa de tu ruta (botón descargar mapa Van). Esperá 100%.
7. Instalá la app: Chrome ⋮ → **Agregar a pantalla principal** → **Instalar**.
8. Cerrá y abrí desde el icono nuevo **SEPSA Campo**. Entrá una vez más con internet.

> No cierres sesión. No borres caché ni datos de Chrome. Un técnico por celular.

## 2. En campo (sin internet)

1. Abrí desde el icono **SEPSA Campo** (no desde WhatsApp ni SMS).
2. Arriba verás **Sin conexión** — es normal, seguí trabajando.
3. Entrá a tu orden → **Registrar visita**.
4. Capturá en este orden:
   - **Lectura** del medidor (foto + número, sin inventar).
   - **GPS** (activá ubicación / alta precisión, esperá el punto).
   - **Evidencia** (fotos claras del medidor y frente).
5. Tocá **Confirmar**. Esperá el mensaje de guardado local.
6. Si no hay señal para autorizar: registrá **Visita / Bloqueo**, guardá y seguí a la siguiente. Volvé después con señal.

**Para cortar, obligatorio con internet:**
Solo tocá ejecutar corte si la app muestra **Autorizada** en ese momento. `Bloqueada`, `unknown`, timeout o sin respuesta = NO cortar.

## 3. Al volver la señal

1. Abrí la app con internet.
2. Entrá a **Cola de sincronización / Pendientes**.
3. Dejá el celular quieto hasta ver **Sincronizado** en todo.
4. Si algo queda **Pendiente / Fallido**, no lo borres. Avisá a supervisión.

## Si algo falla

- **No veo órdenes:** necesitás internet una vez para descargar. Volvé a WiFi, abrí Jornada, sincronizá.
- **Mapa en blanco:** no se descargó. Con internet, descargalo de nuevo.
- **App pide login de otro:** cada celular es de un técnico. Avisá para reasignar online.
- **Render dormido / error red:** tus datos siguen guardados. Reintentá con buena señal.
- **Se apagó el celular:** prendelo, abrí SEPSA Campo, todo sigue ahí.
